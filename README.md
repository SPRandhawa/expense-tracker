# 💰 Expense Tracker

A full-stack Expense Tracker web application built using **Spring Boot**, **Thymeleaf**, and **H2 Database**. This project allows users to securely manage their daily expenses with authentication and a clean UI.

---

## 🚀 Features

- 🔐 User Authentication (Login / Signup)
- ➕ Add Expenses
- ✏️ Edit & Update Expenses
- ❌ Delete Expenses
- 📊 Real-time Total Calculation
- 🗂️ Category & Date Tracking
- 🎨 Modern Dark UI Design

---

## 🛠️ Tech Stack

- **Backend:** Spring Boot (Java)
- **Frontend:** Thymeleaf, HTML, CSS
- **Database:** H2 Database
- **Security:** Spring Security
- **Build Tool:** Maven
